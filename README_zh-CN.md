# PUBG Audio Guard

**PUBG 夜间模式听力保护器** —— 一个"只处理 PUBG 声音"的实时音频处理器：压平枪声/爆炸/手雷的尖峰与闷响、抬高脚步，让你把系统总音量调低保护听力，同时依然听得清。其他程序（语音、提示音、音乐）完全不受影响。

[English](README.md) | `简体中文` | [Русский](README_ru-RU.md) | [Español](README_es-ES.md) | [日本語](README_ja-JP.md)

## 原理

```
PUBG ──> 虚拟声卡(CABLE Input) ──> 本程序(抓取→前置增益→EQ→压缩→限幅→软削波) ──> 耳机
其他所有程序 ────────────────────────────────────────────────────────────┘ 直达，不处理
```

虚拟声卡（VB-Cable，免费）是 PUBG 和耳机之间的"中转站"：PUBG 把声音交给中转站，本程序取出、处理、再送到耳机。压缩器+限幅器把所有峰值锁死在固定天花板下（没有任何声音能炸到你），EQ 切掉手雷的低频"闷压感"和爆炸后游戏故意播放的"耳鸣"高频音效。附加延迟约 70ms，人耳无感。

## 安装

1. **装 VB-Cable**：到 [vb-audio.com/Cable](https://vb-audio.com/Cable/) 下载，右键 `VBCABLE_Setup_x64.exe` → 以管理员身份运行 → **重启电脑**。
2. **装 Python 依赖**：
   ```
   python -m pip install numpy sounddevice scipy
   ```
3. **运行图形界面**：
   ```
   python pubg_audio_gui.py
   ```
   （或双击 `start_gui.bat`）

## 把 PUBG 的声音接进来

GUI 顶部出现绿色"已找到 CABLE Output"提示后，**在游戏运行且正在出声时**：

1. `Alt+Tab` 切回桌面（游戏不用关）
2. 右键任务栏小喇叭 → **打开音量混合器**（或 设置→系统→声音→音量混合器）
3. 找到 PUBG → 把它的**输出设备**改为 **CABLE Input (VB-Audio Virtual Cable)**

Windows 会记住这个设置。其他程序继续用默认输出。

> 游戏没声音？先确认本程序点了【启动】——指向虚拟声卡的 PUBG 在处理程序没开时是无声的。

## GUI 使用

- **启动/停止**：开关处理链
- **测试声音**：合成"脚步+枪声"信号走一遍全链路（不用开游戏）；建议先把系统音量调到 30%
- **旁路对比**：处理/原声一键切换（A/B 对比）
- **预设**：轻度·保留距离感 / 均衡·默认 / 强力·夜间模式
- **电平表**：输入/输出电平，压缩器和限幅器此刻各压了多少 dB
- **悬停任意滑块**：下方显示详细说明和调节建议
- **语言**：右上角下拉框：简体中文 / English / Русский / Español / 日本語
- **保存参数**：写入 `config.json`，下次启动自动加载

## 命令行（可选）

`python pubg_audio.py` 无 GUI 运行（提示信息为中文）。控制命令：`g+`/`g-`（增益）、`t+`/`t-`（阈值）、`r+`/`r-`（比例）、`b`（旁路）、`s`（状态）、`save`、`q`。参数：`--list`、`--selftest`（无声卡 DSP 自测）、`--input`、`--output`、`--gain`、`--threshold`、`--ratio`。

## 参数速查

| 参数 | 默认 | 作用 | 调节 |
|---|---|---|---|
| 前置增益 | +3 dB | 把脚步等小声音整体垫高 | 底噪吵/发闷 → 退 1~2dB |
| 压缩阈值 | -18 dBFS | 超过此响度开始压缩 | 枪声仍吓人 → 调低；远近不分 → 调高 |
| 压缩比 | 2.5:1 | 超出部分保留 1/比例 | 越大越夜间模式，距离感越差 |
| 低频切除 | -8 dB | 去手雷/爆炸/汽车轰鸣的"闷压感" | 还闷 → -12；声音单薄 → 向 0 |
| 高频切除 | -4 dB | 压爆炸后"耳鸣"音效和刺感 | 还刺 → -8；发闷 → 向 0 |
| 限幅上限 | -3 dBFS | 硬红线，任何尖峰不超 | 固定 -3；限幅表常亮说明压缩不够 |
| 启动/释放时间 | 10 / 150 ms | 压缩器反应/恢复速度 | 一般不动 |
| 自动补偿 | 开 | 压缩掉的响度自动补回 | 保持开启 |

## 常见问题

- **装完 VB-Cable 全系统没声音**——安装程序把虚拟声卡设成了系统默认设备。运行包内的 `set_audio_default.ps1`，或在 Windows 声音设置里手动把耳机/麦克风改回默认。GUI 也会对此弹橙色警告。
- **卡顿/爆音**——加大缓冲 `python pubg_audio.py --target 6 --blocksize 960`（延迟稍增）。
- **输出设备不对**——GUI 顶部"播放到"下拉框选择，或 `--output "设备名"`。
- **是外挂吗？会被封号吗？**——不会。本程序只读取系统音频流并播放处理后的副本，不碰游戏进程、内存和网络，BattlEye 不涉及。它和系统级均衡器是同一类工具。
- **PUBG 与 KRAFTON 是其各自所有者的商标。** 本项目非官方、与官方无关联。

## 添加语言

翻译都在 [`i18n.py`](i18n.py)——加一段 `STRINGS["xx_XX"]`（76 个键，缺键自动回退英文）并注册到 `SUPPORTED` 即可，欢迎提交新语言。
