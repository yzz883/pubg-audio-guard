# PUBG Audio Guard

**PUBG 用ナイトモード聴力保護** — PUBG の音だけをリアルタイム処理するオーディオプロセッサ。銃声・爆発・グレネードの「籠もった衝撃」のピークを抑え、足音を持ち上げる。システム音量を下げてもすべて聞こえます。他のアプリ（ボイスチャット・通知）には一切影響しません。

## 仕組み

```
PUBG ──> 仮想ケーブル (CABLE Input) ──> 本アプリ (キャプチャ → プリゲイン → EQ → コンプ → リミッター) ──> ヘッドホン
他のアプリ ───────────────────────────────────────────────────────────────────┘ 直接、未処理
```

仮想ケーブル（VB-Cable、無料）は中継ステーションです。PUBG の出力をそこへ向け、本アプリが音を拾って処理し、ヘッドホンへ出力します。リミッターはすべてのピークを固定の天井以下に保ち、EQ はグレネードの低域「胸に響く感」と爆発後の「耳鳴り」効果音をカットします。追加レイテンシ約 70ms で知覚できません。

## インストール

1. **VB-Cable**: [vb-audio.com/Cable](https://vb-audio.com/Cable/) からダウンロード、`VBCABLE_Setup_x64.exe` を右クリック→*管理者として実行*→**再起動**。
2. **Python パッケージ**: `python -m pip install numpy sounddevice scipy`
3. **起動**: `python pubg_audio_gui.py`（または `start_gui.bat`）

## PUBG の音をルーティング

ゲームが起動して音が出ている状態で: `Alt+Tab` → タスクバーのスピーカーを右クリック → **音量ミキサーを開く** → PUBG を探して出力デバイスを **CABLE Input (VB-Audio Virtual Cable)** に。Windows が設定を記憶します。他アプリは既定の出力のまま。

> ゲームが無音？ 先にアプリの【開始】を押してください — ケーブルへ向かった PUBG は処理アプリなしでは無音です。

## GUI の使い方

- **開始 / 停止** — 処理チェーンの ON/OFF
- **テスト音** — 合成した「足音+銃声」がチェーン全体を通る（ゲーム不要）。先にシステム音量を 30% へ
- **バイパス比較** — 処理あり/なしを即座に切替
- **プリセット** — 軽め / バランス / 強め（ナイトモード）
- **メーター** — 入出力レベルと、コンプ/リミッターが今何 dB 削っているか
- **スライダーにホバー** — 詳細説明と調整のヒントを表示
- **言語** — 右上のドロップダウン
- **設定を保存** — `config.json` に書き込み

## パラメータ

| パラメータ | 既定 | 効果 | 調整 |
|---|---|---|---|
| プリゲイン | +3 dB | 小さい音を先に持ち上げる | ノイズが目立つ → 1〜2 dB 戻す |
| スレッショルド | -18 dBFS | 圧縮開始の音量ライン | 銃声が怖い → 下げる。距離感 → 上げる |
| レシオ | 2.5:1 | 圧縮の強さ | 強い = ナイトモード、距離感低下 |
| 低域カット | -8 dB | グレネードの「こもった衝撃」を除去 | まだ籠もる → -12 |
| 高域カット | -4 dB | 「耳鳴り」効果音と刺々しさを抑制 | まだ刺さる → -8 |
| リミッター上限 | -3 dBFS | ピークの絶対上限 | 固定。メーター満杯＝コンプを強める |

## FAQ

- **VB-Cable 導入後にシステム音声が消えた** — インストーラが既定デバイスを入れ替えます。同梱の `set_audio_default.ps1` を実行するか、Windows のサウンド設定でヘッドホン/マイクを既定に戻してください。GUI も警告します。
- **ノイズ/途切れ** — バッファ増加: `python pubg_audio.py --target 6 --blocksize 960`
- **チート？ BAN？** — いいえ。システムの音声ストリームを読んで処理後のコピーを再生するだけです。ゲームのプロセス・メモリ・ネットワークには触れません。PUBG および KRAFTON は各権利者の商標です。本プロジェクトは非公式です。
